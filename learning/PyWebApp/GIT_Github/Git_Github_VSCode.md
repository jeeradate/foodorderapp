## การแก้เล็กน้อย
ในกรณีที่เราแก้เล็กน้อย ที่แน่นใจว่าจะไม่ทำให้ เกิดความเสียหาย เช่น แก้ Markdown file ก็ใช้วิธีแก้ตรงตามนี้ 
- แก้ File ที่ต้องการ
- เมื่อแก้หมดเสร็จแล้ว ทดสอบแล้ว ก็ Commit เพื่อเป็นการยอมรับสิ่งที่แก้ไป
- จากนั้น Push ขึ้น Github
- ตรวจสอบใน Github ว่าทุกอย่าง Update แล้วหรือยัง
## การแก้ใหญ่
สำหรับการแก้ใหญ่ที่อาจจะกระทบกับการทำงานของโปรแกรม หลัก เช่น การแก้ Code ตาม AI แนะนำ เราต้องสร้าง Branch แล้วทำงานใน Branch และทดสอบจนมั่นใจจึง Merging กับ โปรแกรมหลัก ทำดังนี้
- ก่อนสร้าง Branch ต้อง Commit และ Push ให้เสร็จก่อนนะครับ 
- สร้าง Branch และไปทำงานใน Branch
- แก้ไขตามต้องการ ทดสอบ จนพอใจแล้ว Commit เพื่อเป็นการยอมรับสิ่งที่แก้
- จากนั้นย้ายไป Main แล้วสั่ง Merging กับ Branch ที่ทดสอบแล้ว
- สั่ง Push ขึ้น Github
- ตรวจสอบใน Github ว่าทุกอย่าง Update แล้วหรือยัง
